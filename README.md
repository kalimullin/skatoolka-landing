# Шкатулка — лендинг

Статический интерактивный прототип лендинга для передачи фронтенд-разработчикам. HTML, CSS и JavaScript без сборки и серверных зависимостей.

## Локальный запуск

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8000/`.

## Что включено

- Desktop/mobile лендинг с анимированным фоном, примерами, демонстрациями, тарифами и FAQ.
- Компактная навигация с раскрывающимся меню «Для кого» и мобильным меню.
- Актуальный блок «Всё как вам привычно» и футер с документами, контактами и реквизитами.
- Локальные изображения, иконки и шрифты; лицензии шрифтов находятся рядом с файлами в `assets/fonts/`.

Основная точка входа — `index.html`. Последние изменения хедера и футера находятся в `landing-handoff.css` и `landing-handoff.js`; основные предыдущие дополнения — в `current.css` и `current.js`; существующие слои стилей и сценариев сохранены, чтобы не менять поведение остальных секций. Исходная анимация раскрытия — `gradients-v3.js`.

## Границы прототипа

Регистрация, генерация, оплата и отправка сообщений демонстрационные: backend не подключён. Внешние ссылки ведут на соответствующие страницы Шкатулки. Публикация этого репозитория не обновляет рабочий сайт и не включает автоматический деплой.

В репозитории находится только рабочий лендинг. Архив концептов, клиентские материалы и конфигурация защищённого предпросмотра исключены.
